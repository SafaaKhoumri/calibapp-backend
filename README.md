## 🛠️ Stack Technique

### Frontend
- React · JavaScript

### Backend
- Java Spring Boot · API REST

### Base de données
- Neon (PostgreSQL cloud)

### Déploiement
- VPS Hostinger · Linux · Nginx

## ✨ Fonctionnalités
- Authentification avec redirection par rôle (Admin / Client)
- Gestion des clients et appareils de mesure
- Suivi des sessions d'étalonnage
- Export Excel
- Certificats d'étalonnage
- Système d'alertes
- Reporting
